Weiß
14 Kugeln · 0 Verlustpunkte
Schwarz ist am Zug. Wähle eine Kugel oder eine zusammenhängende Gruppe.
Ziehen: Wähle 1–3 benachbarte eigene Kugeln in einer Linie und tippe dann auf ein benachbartes Zielfeld. Zum Schieben muss die eigene Gruppe zahlenmäßig überlegen sein.
Lokales Spiel: Beide Personen spielen abwechselnd auf diesem Handy.
Regeln kurz erklärt
  • Jeder startet mit 14 Kugeln. Wer zuerst 6 Verlustpunkte verursacht, gewinnt. Eine Bombe zählt beim Herausschieben 2 Punkte.
  • Jede Seite hat eine zufällig markierte Bombe (rotes X). Wird sie herausgeschoben, zählt sie 2 Verlustpunkte. Die Explosion ist ein visueller Effekt; benachbarte Kugeln bleiben auf dem Brett.
  • Eine Kugel oder eine zusammenhängende Gruppe aus 2 oder 3 Kugeln darf um ein Feld bewegt werden.
  • Inline: Die Gruppe bewegt sich entlang ihrer Linie. Gegnerische Kugeln dürfen geschoben werden, wenn die eigene Gruppe größer ist als die gegnerische Reihe und dahinter ein freies Feld oder der Brettrand liegt.
  • Seitwärts: 2 oder 3 eigene Kugeln können gemeinsam seitwärts auf freie Felder gleiten; alle Zielfelder müssen frei sein.
  • Eine Gruppe darf nicht durch eigene oder gegnerische Kugeln blockiert werden. Einzelne Kugeln können nicht seitwärts als Gruppe bewegt werden.

Die App prüft die üblichen Standardzüge und zählt herausgeschobene Kugeln. Im Zeitspiel hat jede Seite eine eigene Uhr. Die Uhr der jeweils aktiven Seite läuft; wer zuerst abläuft, verliert.
